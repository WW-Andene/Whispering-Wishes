# Empirical Drop Rates — Community Data (Wuthering Waves Data Gathering)

Source: user-provided "Wuthering Waves - Drop Rates.csv", a community-crowdsourced spreadsheet (credited in-sheet to the "Wuthering Waves Data Gathering" Discord server: https://discord.gg/HHNCWmy29q). Transcribed verbatim 2026-09-06 — this is **empirical average material/Echo/EXP yield per run**, tracked by real player submissions, not an official disclosure like the substat tables in `Probability.md`. `#REF!` cells are broken-formula artifacts already present in the source sheet, kept as-is rather than guessed at.

All "Union Level"/"SOL3 Phase" rows below are keyed to the same 8 progression tiers the sheet uses throughout (UL1/SOL1 → UL70/SOL8).
