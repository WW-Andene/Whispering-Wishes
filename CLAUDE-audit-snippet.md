# Audit Skills

When asked to audit, review, or analyze an app or file, read the relevant skill file BEFORE starting any work:

- **App audit** (code, security, performance, a11y, UX, architecture): Read `docs/skills/app-audit/SKILL.md`
- **Design audit** (visual design, color, typography, motion, brand identity): Read `docs/skills/design-aesthetic-audit/SKILL.md`

If the user doesn't specify which audit, ask them to choose: Full App Audit, Design & Aesthetic Audit, or Both (Companion Mode).
